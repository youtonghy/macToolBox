# 滚轮可调滑杆设计

## 目标

让 ToolBox 中全部 SwiftUI 滑杆在鼠标指针位于控件上时支持滚轮调整，同时保留原有拖拽、键盘、禁用态、控件尺寸和无障碍行为。

## 范围

替换以下界面中的 6 处滑杆用法：

- 外接显示器弹窗中的亮度、对比度和音量控制
- 分应用音量弹窗
- 显示器设置页
- 分应用音量设置页
- 亮度计划时段编辑器及新增时段表单

不改变任何滑杆现有的数值范围、步长、绑定写入逻辑、标签或提示文本。

## 方案

新增一个共享的 `ScrollWheelSlider` SwiftUI 组件。组件通过 `NSViewRepresentable` 管理 `NSSlider` 子类，由 AppKit 控件继续负责原生拖拽、键盘操作和无障碍语义。

`NSSlider` 子类覆盖 `scrollWheel(with:)`。事件只有在指针命中滑杆且控件可用时才会到达该方法；有效的垂直滚动会被滑杆消费，避免同时滚动外层设置页面。

组件从 SwiftUI 环境同步 `isEnabled` 和 `controlSize`，并在 `updateNSView` 中同步绑定值、范围和步长。AppKit 的 target/action 在拖拽或键盘操作后写回 SwiftUI 绑定，滚轮调整也沿用同一写回路径。

## 数值规则

- 向上滚动增加数值，向下滚动减少数值。
- 普通鼠标滚轮每个事件只按方向调整一个滑杆步长，不使用系统加速后的增量幅度，避免快速滚动时越过目标值。
- 精细滚动设备先累计垂直滚动量，达到固定阈值后调整一个或多个步长，避免触控板单次手势产生过多变化。
- 滚动方向反转时清除未达到阈值的旧方向余量，避免反向操作延迟。
- 每次结果按步长对齐，并钳制到闭区间范围内。
- 控件禁用时不修改绑定值。
- 水平滚动不调整数值，也不作为本功能的输入。

数值计算放在独立的小型值类型中，UI 事件层只负责提供滚动增量并应用计算结果。这使边界、方向、步长和累计行为可以用 XCTest 直接验证。

## 错误与边界处理

组件构造时要求范围有效且步长为正数。现有调用点都满足该约束。浮点结果在写回前进行步长对齐和范围钳制，避免累积误差或越界。

达到最小值或最大值后，继续同方向滚动仍由滑杆消费，但绑定值保持不变。这样不会因到达边界而突然开始滚动父级页面。

## 验证

新增聚焦 XCTest，覆盖：

- 普通滚轮的增减方向和单步变化
- 非单位步长及非零范围下限的对齐
- 最小值和最大值钳制
- 精细滚动的累计、跨越多个阈值及方向反转
- 禁用态不产生变化

实现后运行聚焦测试、完整 `ToolBoxTests`、Debug 构建和 `git diff --check`。由于 XCTest 不能完整模拟真实鼠标与触控板手感，仍需在应用中手动确认悬停命中、滚动方向、灵敏度以及嵌套滚动视图中的事件消费。
